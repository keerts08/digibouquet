# digiflority
digiflority is a little website where you can create your own digital bouquet, add a tiny note, and share it with someone you love. It combines the ideas behind DigiBouquet and Flority, with more freedom to customize how your bouquet looks and how the flowers are arranged.

I built this project for someone I liked, so the idea was to make something a little more personal than just sending a regular message. You can put together your own bouquet, arrange the flowers however you want, write a small note, and send the finished creation to someone special.

# Features
- Create your own digital flower bouquet
- Customize the flowers and their arrangement
- Add a personalized note to your bouquet
- Share your finished bouquet with other people
- A simple, interactive experience for making something personal

## Getting Started

### Dependencies

You'll need:

- Node.js
- npm
- A modern web browser

### Installing

1. Clone the repository:

```bash
git clone https://github.com/keerts08/digibouquet
```

2. Navigate into the project directory:

```bash
cd digibouquet
```

3. Install the dependencies:

```bash
npm install
```

### Executing

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal (usually `http://localhost:3000`) to access digiflority.

## Help

If the project doesn't start, make sure Node.js is installed and that you've run `npm install` inside the project directory. If a port is already in use, stop the other process using it or let the development server choose another port.
